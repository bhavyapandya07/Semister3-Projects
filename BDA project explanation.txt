🧠 What Your Project Does (In Simple Words)
Your project is a Big Data Recommendation System — similar to what Amazon or Netflix uses. It:

Reads 2.7 million real shopping events from RetailRocket (a real Russian e-commerce company)
Trains an AI model (ALS) to understand user preferences
Predicts the top 5 products each user is most likely to buy next
Displays everything in a beautiful interactive dashboard
🔑 The 3 Key Concepts to Know Cold
1. Apache Spark (Big Data Engine)
Regular Python/Pandas can't handle 2.7M rows on one machine efficiently. Spark splits the data across all CPU cores and processes chunks in parallel. The same code runs on a laptop or a 1000-node cloud cluster — just change one line.

2. ALS Algorithm (The Recommendation Brain)
ALS (Alternating Least Squares) is matrix factorization — it represents every user and every product as a list of 20 hidden numbers ("taste vectors"). The dot product of a user's vector × an item's vector = how much the user would like that item. It "alternates" between solving for users and items until it converges. Used by Netflix, Spotify, and Alibaba.

3. Implicit Feedback
You have no star ratings — only behaviour signals. view=1.0, addtocart=3.0, transaction=5.0. The model treats these as implicit signals of preference, not explicit ratings. This is why implicitPrefs=True is set.
